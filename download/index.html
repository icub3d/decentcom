Frequently Asked Questions

Is there a web client?
Currently, decentcom is focused on a desktop application for better security (private keys are stored in the OS keychain and signing happens in the Rust core, not the browser).
How do I host my own server?
A server can be run as a single binary or a Docker container. Check the server documentation for instructions.
